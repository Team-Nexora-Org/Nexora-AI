    38→    38→1. PROBLEM CONTEXT
    39→    39→
    40→    40→Real infrastructure projects already have structured project schedules in systems such as Primavera P6, Microsoft Project, or other PMIS platforms.
    41→    41→
    42→    42→The project schedule contains planned L5/L6 activities.
    43→    43→
    44→    44→However, actual execution information is distributed across multiple supervisors and disciplines.
    45→    45→
    46→    46→Examples:
    47→    47→
    48→    48→* Piping supervisor
    49→    49→* Civil supervisor
    50→    50→* Mechanical supervisor
    51→    51→* Electrical supervisor
    52→    52→* Instrumentation supervisor
    53→    53→
    54→    54→They may report through:
    55→    55→
    56→    56→* Voice
    57→    57→* Text
    58→    58→* Daily progress reports
    59→    59→* Excel
    60→    60→* Site diaries
    61→    61→* PDFs
    62→    62→* Photos
    63→    63→
    64→    64→The terminology used by the field does not necessarily match the terminology used by the schedule.
    65→    65→
    66→    66→Example:
    67→    67→
    68→    68→Schedule:
    69→    69→
    70→    70→“A10931 — Erect Spool Line 24-XX”
    71→    71→
    72→    72→Field:
    73→    73→
    74→    74→“Line 24-XX ka spool erection complete hai.”
    75→    75→
    76→    76→Another:
    77→    77→
    78→    78→“24-XX spool fixed and erection finished.”
    79→    79→
    80→    80→Another:
    81→    81→
    82→    82→“Piping team completed erection of the 24-XX spool.”
    83→    83→
    84→    84→These statements can represent the same planned activity.
    85→    85→
    86→    86→The problem is therefore not merely data entry.
    87→    87→
    88→    88→The core problem is:
    89→    89→
    90→    90→HETEROGENEOUS FIELD EXECUTION DATA MUST BE INTERPRETED AND RECONCILED AGAINST STRUCTURED L5/L6 PROJECT SCHEDULE ACTIVITIES.
    91→    91→
    92→    92→The planner should not have to manually read every report, determine what happened, find the corresponding schedule activity, calculate progress, and update the schedule from scratch.
    93→    93→
    94→    94→NEXORA is the intelligent reconciliation layer between field execution and the existing project schedule.
